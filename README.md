# Blinkit Grocery Sales Dashboard

Interactive Excel dashboard project built using Microsoft Excel.

## Features
- KPI Cards
- Pivot Tables
- Slicers
- Interactive Charts
- Sales Analysis

## Tools Used
- Microsoft Excel

## Project Goal
To analyze grocery sales performance by outlet size, location, and item type.
